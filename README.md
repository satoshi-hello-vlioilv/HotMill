# HotMill — アルミニウム熱間可逆圧延シミュレータ

4段可逆式（4-High Reversing）アルミニウム熱間圧延機を、設備構造・圧延理論・操作系まで含めて
ブラウザ上で再現する単一ファイルアプリケーションです。`index.html` を開くだけで動作します
（three.js を unpkg から読み込むため、初回はネットワーク接続が必要です）。

---

## 1. 対象設備の諸元

| 項目 | 値 | 出典 |
|---|---|---|
| ワークロール | Φ935 × 2500 mm | 実機仕様 |
| バックアップロール | Φ1430 × 2450 mm | 実機仕様 |
| 最大圧延速度 | 161 mpm | 実機仕様 |
| 常用最大圧延荷重 | 3,920 ton | 実機仕様 |
| 非常最大圧延荷重 | 4,200 ton | 実機仕様 |
| 入側テーブル長 | 121.8 m | 実機仕様 |
| 出側テーブル長 | 80.1 m | 実機仕様 |
| パスライン高さ | 900 mm | **推定値** |
| 主電動機容量 | 14 MW (2×7 MW) | **推定値**（スケジュール最大動力 11.7 MW から設定） |

テーブル長が入側 121.8 m / 出側 80.1 m と非対称なのは、最終パスで板が大きく伸びるためです。
最大寸法スラブ（600 × 2200 × 6000 mm）を最終 60 mm まで圧延すると板長は 60 m に達し、
噛み出し余裕 8 m を加えた 68 m がテーブル長の要求値になります。

パスラインは**調整装置（ステップウェッジ）付き**の構成としています。圧延中は下ワークロール上面が
パスラインで固定され、圧下はすべて上側（油圧圧下シリンダ）で行います。

## 1-2. スラブ装入設備の配置

ライン直近（側方 3.8 m）のオペレータ側に置いています。流れは実機どおり
**転倒装置で縦置きインゴットを倒す → そのまま進行方向(+X)へ縦送り → 横送りローラが上昇してライン側へ移載**。

| 項目 | 値 |
|---|---|
| ライン中心からの側方距離 | 3,800 mm（主テーブル架台と 190 mm 離隔） |
| 転倒軸位置 | X = −14,400 mm（移載位置まで 8.1 m） |
| 転倒アーム長 | 6,000 mm（最大インゴット長 6 m を受ける） |
| 縦送りローラ | X = −8,100 〜 −2,700 mm、900 mm ピッチ（主テーブルと同一グリッド） |
| 横送りローラ | X = −7,650 / −6,750 / −5,850 / −4,950 mm（縦送り・主テーブルの中間） |
| 横送りローラ昇降 | 260 mm。退避時は縦送りローラ面より下、移載時のみ上昇してパスラインに一致 |
| 移載完了位置 | X = −6,300 mm |

**駆動側（−Z）には置けません。** スピンドル（Z = −3,400 mm）、ピニオンスタンド、減速機、主電動機が
占有しているためで、実機でも材料ハンドリングは操作側、駆動は駆動側に分離されます。

横送りローラは縦送り／主テーブルの中間に配置し、胴長 420 mm をローラ間隙 500 mm に収めた上で、
移載時のみ上昇する可動スキッド方式としています。これにより縦方向搬送と横方向移載が
同一のパスライン高さで両立します。

## 2. 圧延モデル

`Rolling` オブジェクト（純関数の集合）に集約しています。状態を持たないため単体で検証できます。

| 量 | 式 |
|---|---|
| 接触弧長 | `Ld = √(R·Δh − Δh²/4)` |
| 変形抵抗 | `kf = C·exp(−b(T−Tref))·ε̇^m` （C=55 MPa, Tref=450 ℃, b=0.0055 /℃, m=0.10：Al-Mg 系相当） |
| 平均ひずみ速度 | `ε̇ = (v/Ld)·ln(hIn/hOut)` |
| 摩擦丘係数 | `Qp = (exp(x)−1)/x`,  `x = μ·Ld/hm` （スラブ法。x→0 で 1 に収束、μ=0.25） |
| 平均面圧 | `pm = 1.155·kf·Qp` （1.155 は平面ひずみ係数） |
| 圧延荷重 | `P = pm·w·Ld` |
| トルク／動力 | `M = 2·P·λ·Ld`,  `Power = M·ω`（λ=0.45） |
| 加工発熱 | `ΔT = η·1.155·kf·ln(hIn/hOut)/(ρ·cp)`（η=0.95） |
| ロール抜熱 | 接触時間 `tc = Ld/v` と熱伝達率 30 kW/m²K による集中定数モデル |
| 表面放熱 | 放射（ε=0.18）＋対流。板厚に反比例して効く |

板長・板厚は**質量流一定**（出側速度 = ロール周速、入側速度 = 出側速度 × hOut/hIn）で積分するため、
体積が原理的に保存されます（実測誤差 −0.066 %）。

### 検証結果（幅 1500 mm・400 mm → 60 mm・7 パス）

最大圧延荷重 **1,643 t**（常用最大の 42 %）／最大主機動力 **11.7 MW**。
最大幅 2200 mm・重圧下の条件では荷重 3,063 t（常用最大の 78 %）に達し、
「常用最大 3,920 t」という仕様と整合します。

### 意図的に採用しなかった表現

アルミニウムの熱間圧延温度域（400–540 ℃）では材料は**可視発光しません**（赤熱は 600 ℃ 以上）。
そのため赤熱表現は行わず、温度は色味と表面粗さの微差、および水蒸気・クーラント演出で示しています。
クーラントも材料への直接噴射ではなく、実機同様ワークロール面への潤滑エマルジョン噴射としています。

## 3. 構造

```
CONFIG          全寸法を mm 単位で保持する単一の真実。3D 空間へは Sim.u() でのみ変換する
Num             時間積分ユーティリティ（approach / rateTo）。dt 非依存を構造的に保証する
Rolling         圧延理論（純関数）
State           SlabState / MillState / SupplyState / ShearState
Controller      MillController / SupplyController / ShearController
PhysicsEngine   任意 dt を受け取り 1/120 s の固定ステップに分割して積分
MAT / G / Parts マテリアル登録・ジオメトリ生成器・部材ライブラリ
View            MillStand / Drive / Table / Guide / Shear / Supply / Slab / Spray / Label
World3D         シーン・ライティング・カメラ・描画品質
UIManager       操作系・計器・状態バナー
```

`PhysicsEngine.update(dt)` は内部で固定ステップに分割するため、**12 fps でも 144 fps でも結果が一致します**
（最終板長 26.24 m で完全一致）。シミュレーション速度スライダは入力 dt を倍率変更するだけで、
物理結果には影響しません。

## 4. 描画性能

| 指標 | 値 |
|---|---|
| ドローコール | 40–56（カメラ位置による） |
| 描画三角形 | 約 37,000 |
| ユニークジオメトリ | 43 |

繰り返し部材（テーブルローラ約 160 本・架台・ガイドローラ・チョック等）は `InstancedMesh` に集約し、
テーブルは区間分割して視界外をフラスタムカリングで落としています。静的部材は `mergeGeometries` で
1 メッシュに畳んでいます。

環境反射（PMREM）はフラグメント単価が高いため、**磨かれた金属部材にのみ**適用し、画面占有面積の
大きい塗装構造物・床には適用していません。描画品質は「高 / 標準 / 軽量」で切り替えられ、
起動直後にフレームレートを実測して 20 fps を下回る環境では自動的に軽量へ切り替わります。

## 5. 自動検査

構造的な破綻が無いことは、目視ではなく判定式で確認しています（20 項目すべて合格）。

- ワークロールとバックアップロールの外接
- 下ワークロール上面 = パスライン、圧下してもパスラインが動かないこと
- テーブルローラ上面 = パスライン、圧延機直下・シャー直下にローラが無いこと
- テーブルローラ同士／横送りローラと主テーブルローラの非干渉
- 縦送りテーブルと主テーブルの側方離隔、転倒アームと横送り／縦送りローラの非干渉
- 転倒アーム長 ≥ 最大インゴット長、倒した状態でベッドローラ上面 = パスライン
- 横送りローラと入側サイドガイドの非干渉、横送りローラの退避高さ
- スラブがロール面へ食い込まないこと、出側板厚がギャップと一致すること
- 最大材長がテーブル長に収まること
- サイドガイドが板幅未満に閉じないこと
- テーブル架台が床に接地していること

回転方向についても、材料が +X へ進むとき上ワークロールが +Z、下ワークロールとテーブルローラが
−Z 回転であることを符号で検証しています。

## 6. 操作

| キー | 動作 |
|---|---|
| `Space` | 圧延サイクル開始 / 中止 |
| `P` | 一時停止 / 再開 |
| `R` | リセット |
| `L` | 設備ラベル表示切替 |
| `C` | ハウジング断面表示切替（実体 / 半断面 / 透視） |
| `1`–`6` | 視点切替（全景 / 圧延機 / ロールバイト / 駆動側 / 装入設備 / クロップシャー） |
