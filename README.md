# HotMill — アルミニウム熱間可逆圧延シミュレータ

4段可逆式（4-High Reversing）アルミニウム熱間圧延機を、設備構造・圧延理論・操作系まで含めて
ブラウザ上で再現する単一ファイルアプリケーションです。`index.html` を開くだけで動作します
（three.js を unpkg から読み込むため、初回はネットワーク接続が必要です）。

---

### 最大圧延速度は独立した仕様ではない

`330 rpm ÷ 5.96 = 55.4 rpm`（ロール）× `π × 0.930 m` = **161.8 mpm**。
別に与えられていた「最大圧延速度 161 mpm」と一致します。つまり最高速度は
モータ最高回転数・減速比・ロール径から決まる従属値なので、`Drive.maxSpeed()` で導出しています。
ロールを研削して径が小さくなれば最高速度も下がります（Φ885 では 154 mpm）。

直流機は **基底回転数 150 rpm までが定トルク、そこから 330 rpm までが定出力**です。
これを駆動包絡線としてそのままモデル化しました。

- ロール軸最大トルク = `(1,900 kW × 2) ÷ (150 rpm) × 5.96` ≒ **1,442 kN·m**
- 所要トルクが大きいパスほど出せる速度が下がる（定出力域では速度と反比例）

実際、巻取パスでは速度上限が 111 → 89 mpm と低下していく挙動が出ます。
運転時のリミッタもこの包絡線で動くため、圧延荷重が上がると自動的に減速します。

### テーブル長が非対称な理由

**入側 121.8 m は「巻取直前のパスで板が載りきる長さ」そのものです。**
呼び厚 406（面削後 382 mm）× 長さ 4,200 mm のスラブを 8 mm まで圧延すると板長は約 200 m に達し、
テーブルには載りません。逆算すると、テーブル上で往復できる最薄は入側 121.8 m ÷ 伸び ≒ 14.5 mm。
そこから最終 1 パスで 8 mm へ落として巻き取る、という構成になります。
実際に生成されるスケジュールでも第 8 パス後の板長は **110.6 m** で、入側テーブル長にちょうど収まります。
つまり巻取リールは付加設備ではなく、この板厚を作るための必須設備です。

### ロール研削とパスライン調整装置

ロールは研削のたびに径が小さくなります（WR Φ930→Φ885、BUR Φ1430→Φ1350）。
下ワークロール上面をパスラインに保つには、減径ぶん（最大 62.5 mm）を下バックアップロール
チョックの下で持ち上げる必要があり、それがパスライン調整ウェッジの役割です。
サイドバーの「ロール研削状態」を動かすと、ロール径の変化とウェッジの厚み変化が連動します。

テーブルローラは胴端 Φ281.6 部で材料を支持し、中央へ向かう 1:25 のテーパで自動調心します。
したがってパスラインの基準は胴端半径（140.8 mm）です。

### スラブ諸元

| 項目 | 値 |
|---|---|
| 呼び厚（鋳造厚） | 406 / 508 / 560 mm |
| 面削量 | 片面 8〜15 mm（両面）。圧延前の実厚 = 呼び厚 − 2×面削量 |
| 長さ | 最大 4,200 mm |
| 幅 | 900〜2,200 mm |

面削面（横置きしたときの上下面）は鏡面状に仕上がるため、鋳肌のままの側面・端面とは
別のマテリアルを割り当てています（BoxGeometry の +Y / −Y グループのみ鏡面）。

### ラインの向き

`CONFIG.FLIP` が第1パスの進行方向を決めます。寸法はすべて「第1パスが +X」の正準向きで
記述し、`mirrorLayout()` が X 座標とパス方向をまとめて折り返します。個々の箇所で
符号を書き分けないので、入側／出側の左右反転は定数 1 個で切り替わります。

パスラインは**調整装置（ステップウェッジ）付き**の構成としています。圧延中は下ワークロール上面が
パスラインで固定され、圧下はすべて上側（油圧圧下シリンダ）で行います。

## 1-2. スラブ装入設備の配置

ライン直近（側方 3.8 m）のオペレータ側に置いています。スラブはピット炉で立てたまま加熱され、
装入クレーンで吊り上げられて転倒機に立てかけられ、倒されてラインへ送り込まれます。

工程は `CONFIG.SEQUENCE` の並びがそのまま定義になります（7工程）。

| # | 工程 | 内容 |
|---|---|---|
| 1 | 蓋開 | ピット炉の蓋をスライドさせて開く |
| 2 | 吊上げ | 加熱済みスラブを立てたままクレーンで炉から引き上げる |
| 3 | 横行 | トロリが転倒機まで横行する |
| 4 | 立てかけ | 転倒機の受け面へ降ろす（この時点でスラブは直立） |
| 5 | 転倒 | 転倒アームが 90° 倒し、ベッドローラ上に平置きにする |
| 6 | 縦送り | 進行方向へ搬送する |
| 7 | 横送り | 横送りローラが上昇してミルラインへ移載する |

| 項目 | 値 |
|---|---|
| ライン中心からの側方距離 | 3,800 mm（主テーブル架台と 190 mm 離隔） |
| 転倒軸位置 | ライン方向に移載位置から 6.9 m |
| 転倒アーム長 | 4,600 mm（最大スラブ長 4,200 mm を受ける） |
| 縦送りローラ | 900 mm ピッチ（主テーブルと同一グリッド） |
| 横送りローラ | 縦送り・主テーブルの中間（グリッドの中点） |
| ピット炉 | 深さ 5,200 mm（最大スラブ長 4,200 mm を立てて収める） |
| 横送りローラ昇降 | 260 mm。退避時は縦送りローラ面より下、移載時のみ上昇してパスラインに一致 |
| 吊上げクリアランス | 床上 2,600 mm |

**駆動側（−Z）には置けません。** スピンドル（Z = −3,400 mm）、ピニオンスタンド、減速機、主電動機が
占有しているためで、実機でも材料ハンドリングは操作側、駆動は駆動側に分離されます。

横送りローラは縦送り／主テーブルの中間に配置し、胴長 420 mm をローラ間隙 500 mm に収めた上で、
移載時のみ上昇する可動スキッド方式としています。これにより縦方向搬送と横方向移載が
同一のパスライン高さで両立します。

## 2. 圧延モデル

`Rolling` オブジェクト（純関数の集合）に集約しています。状態を持たないため単体で検証できます。

| 量 | 式 |
|---|---|
| 接触弧長 | `Ld = √(R·Δh − Δh²/4)` |
| 変形抵抗 | `kf = C·exp(−b(T−Tref))·ε̇^m` （C=55 MPa, Tref=450 ℃, b=0.0055 /℃, m=0.10：Al-Mg 系相当） |
| 平均ひずみ速度 | `ε̇ = (v/Ld)·ln(hIn/hOut)` |
| 摩擦丘係数 | `Qp = (exp(x)−1)/x`,  `x = μ·Ld/hm` （スラブ法。x→0 で 1 に収束、μ=0.25） |
| 平均面圧 | `pm = 1.155·kf·Qp` （1.155 は平面ひずみ係数） |
| 圧延荷重 | `P = pm·w·Ld` |
| トルク／動力 | `M = 2·P·λ·Ld`,  `Power = M·ω`（λ=0.45） |
| 加工発熱 | `ΔT = η·1.155·kf·ln(hIn/hOut)/(ρ·cp)`（η=0.95） |
| 前方張力 | 巻取パスでは `kf` を張力ぶん低下させる（22.5 ton を板断面積で割った値、上限 30 MPa） |
| ロール抜熱 | `ΔT = (T−T_roll)(1 − exp(−2·h_c·t_c/(ρ·cp·h)))`、h_c = 30 kW/m²K。指数形で飽和させる |
| 表面放熱 | 放射（ε=0.18）＋自然対流（14 W/m²K）。板厚に反比例して効く |
| コイル外径 | `OD = √(ID² + 4·L·h/π)`（内径 Φ610 から成長） |

可逆圧延で材料温度を決める主因はロール抜熱です。線形式は低速・厚板で発散するため
指数形（飽和する集中定数解）を使っています。クーラントはロール面への噴射なので、
材料側の強制対流としては扱っていません（材料に直接かけるモデルは温度を過剰に下げます）。

板長・板厚は**質量流一定**（出側速度 = ロール周速、入側速度 = 出側速度 × hOut/hIn）で積分するため、
体積が原理的に保存されます（実測誤差 −0.066 %）。

### パススケジュールの自動生成

パス数と圧下量は板厚・板幅から `Rolling.buildSchedule()` が生成します。
1パスあたりの圧下量は **噛み込み角（24°）・圧下率（40 %）・圧延荷重（常用最大の 88 %）** の
3つで律速し、速度は質量流に合わせて上げたうえで **主機動力 3,800 kW の 84 %** で頭打ちにします。
温度は選んだ速度に依存する（低速ほどロールに熱を奪われる）ため、速度→温度→速度 を
反復して収束させています。可逆圧延なので最終材が出側に残るようパス数は奇数にそろえます。

パスは次の3つで律速します。

1. **噛み込み角 24°** — 前段の厚板パスはこれで圧下量が決まる
2. **テーブル長** — 中間パスは終わる側のテーブルに板が載りきる必要がある
3. **主駆動系の包絡線** — 後段の低温パスは所要トルクで速度が決まる（定トルク／定出力）

さらに「各パスを所定時間（150 秒）内に通し切れるか」も条件に入れています。長いパスほど
速く通す必要があり、そこで定格動力を超えるなら圧下量を落とします。温度は速度に依存するので
速度→温度→速度を反復して収束させます。

**検証結果**（呼び厚 406 − 面削 2×12 = 382 mm、幅 1,500 mm、コイル 8 mm）:

| 指標 | 値 |
|---|---|
| パス数 | 9（可逆・最終パスで巻取） |
| 最大圧延荷重 | 2,519 t（常用最大 3,920 t の 64 %） |
| 最大主機動力 | 3,161 kW（定格 3,800 kW の 83 %） |
| 巻取温度 | 320 ℃ |
| コイル | 外径 Φ1,553 ／ 6,355 kg ／ 仕上げ幅 1,470 mm |
| サイクル時間 | 688 秒（11.5 分） |

重圧下パスは低速（25〜40 mpm）、薄板パスは高速という実機どおりの姿になります。
主機は定格を超えるトルクを出せないため、運転時にも動力リミッタで自動的に減速します。

### 意図的に採用しなかった表現

アルミニウムの熱間圧延温度域（400–540 ℃）では材料は**可視発光しません**（赤熱は 600 ℃ 以上）。
そのため赤熱表現は行わず、温度は色味と表面粗さの微差、および水蒸気・クーラント演出で示しています。
クーラントも材料への直接噴射ではなく、実機同様ワークロール面への潤滑エマルジョン噴射としています。

## 3. 構造

```
CONFIG          全寸法を mm 単位で保持する単一の真実。3D 空間へは Sim.u() でのみ変換する
Num             時間積分ユーティリティ（approach / rateTo）。dt 非依存を構造的に保証する
Rolling         圧延理論（純関数）
State           SlabState / MillState / SupplyState / ShearState
Controller      MillController / SupplyController / ShearController
PhysicsEngine   任意 dt を受け取り 1/120 s の固定ステップに分割して積分
MAT / G / Parts マテリアル登録・ジオメトリ生成器・部材ライブラリ
View            MillStand / Drive / Table / Guide / Shear / Supply / Slab / Spray / Label
World3D         シーン・ライティング・カメラ・描画品質
UIManager       操作系・計器・状態バナー
```

`PhysicsEngine.update(dt)` は内部で固定ステップに分割するため、**12 fps でも 144 fps でも結果が一致します**
（最終板長 26.24 m で完全一致）。シミュレーション速度スライダは入力 dt を倍率変更するだけで、
物理結果には影響しません。

## 4. 描画性能

| 指標 | 値 |
|---|---|
| ドローコール | 40–56（カメラ位置による） |
| 描画三角形 | 約 37,000 |
| ユニークジオメトリ | 43 |

繰り返し部材（テーブルローラ約 160 本・架台・ガイドローラ・チョック等）は `InstancedMesh` に集約し、
テーブルは区間分割して視界外をフラスタムカリングで落としています。静的部材は `mergeGeometries` で
1 メッシュに畳んでいます。

環境反射（PMREM）はフラグメント単価が高いため、**磨かれた金属部材にのみ**適用し、画面占有面積の
大きい塗装構造物・床には適用していません。描画品質は「高 / 標準 / 軽量」で切り替えられ、
起動直後にフレームレートを実測して 20 fps を下回る環境では自動的に軽量へ切り替わります。

## 5. 自動検査

構造的な破綻が無いことは、目視ではなく判定式で確認しています（28 項目すべて合格）。

- ワークロールとバックアップロールの外接
- 下ワークロール上面 = パスライン、圧下してもパスラインが動かないこと
- テーブルローラ上面 = パスライン、圧延機直下・シャー直下にローラが無いこと
- テーブルローラ同士／横送りローラと主テーブルローラの非干渉
- 縦送りテーブルと主テーブルの側方離隔、転倒アームと横送り／縦送りローラの非干渉
- 転倒アーム長 ≥ 最大インゴット長、倒した状態でベッドローラ上面 = パスライン
- 横送りローラと入側サイドガイドの非干渉、横送りローラの退避高さ
- スラブがロール面へ食い込まないこと、出側板厚がギャップと一致すること
- 最大材長がテーブル長に収まること
- サイドガイドが板幅未満に閉じないこと
- テーブル架台が床に接地していること
- テーブルローラの胴端径・中央径が図面値と一致し、中央が細い自動調心形状であること
- 第1パスが設定した向きへ進み、入側テーブルがその上流側、クロップシャーが出側にあること
- ピット炉の深さが最大スラブ長以上で、吊上げクリアランスが炉口・転倒機を越えること
- 巻取パス以外は必ずテーブルに載ること、最終パスが巻取パスで出側へ向かうこと
- 出側設備が図面どおりの間隔（5,875 / 6,900 / 8,350 mm）で出側にあること
- 最大コイル外径でもコイル下端がパスラインより上にあること（可逆パス中の板が下を通れる）

回転方向についても、材料が +X へ進むとき上ワークロールが +Z、下ワークロールとテーブルローラが
−Z 回転であることを符号で検証しています。
