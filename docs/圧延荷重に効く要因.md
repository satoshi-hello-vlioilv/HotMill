# 圧延荷重に効く要因 —— 影響の大きい順

熱間可逆ミル（アルミ）の圧延荷重が「何で・どれだけ・どう」動くかを、
**本シミュレータの実装を実際に測った数字**で並べた資料です。

> **数字の出どころ**
> この資料の数値はすべて `node tools/sensload.mjs` と `node tools/mtrace.mjs`、
> `node tools/modeltrace.mjs` の出力です。推論で書いた数字はありません。
> モデルを直せば数字も変わるので、**引用するときは版数（画面右上のバッジ）を添えてください**。
> 代表条件は実機ロット（A5052・530 × 1,330 × 3,450 mm）のスケジュールから
> 厚板・中間・仕上げ・巻取を 1 本ずつ取ったものです。

---

## 0. 3 分で掴む —— 結論

### 荷重はこの 1 本の式でできている

```
      F  =  w  ×  Ld  ×  p̄
      │      │      │      └─ 平均面圧 ＝ 1.155 × kf × Qp
      │      │      └──────── 接触弧長 ＝ √(R' × Δh)
      │      └─────────────── 板幅
      └────────────────────── 圧延荷重
```

- **`kf`（変形抵抗）** … 材料が「どれだけ硬いか」。**材質・温度・ひずみ速度**で決まる。
- **`Qp`（摩擦丘係数）** … 材料はロールとの摩擦で横へ逃げられず、接触面の圧力が
  中央へ向かって山のように盛り上がる。その**山の高さ**。
  **`Ld/h̄`（接触弧長 ÷ 平均板厚）と `μ`** で決まる。
- **`Ld`（接触弧長）** … ロールが材料に触れている長さ。**ロール径と圧下量**で決まる。

**この 3 つのどれを通って効くのか**を見分けられれば、要因の整理は終わりです。

### 影響の大きい順（実測）

「実機でその量が振れる幅ぶん動かしたら、荷重は何 % 動くか」で並べています。
**感度（1 % 動かしたら何 %）ではなく、実際に動く幅を掛けた «影響度»** です ——
感度が大きくても現場で動かない量（ロール径）は、実際には効かないからです。

| 順 | 要因 | 影響度（荷重の変化） | どこを通って効くか | 現場で振れる幅 |
|---|---|---|---|---|
| **1** | **材質（変形抵抗の絶対値）** | **+280 %**（A1050 615 t → A7075 2,334 t） | `kf` | 品種で決まる |
| **2** | **圧下量 Δh** | **+34 〜 +138 %** | `Ld`（√Δh）＋ `Qp`（Ld/h̄）＋ `kf`（ひずみ・過渡） | パス設計で 2 倍 |
| **3** | **板幅 w** | **+60 %**（きっちり比例） | `w` | 1,000 → 1,600 mm |
| **4** | **温度 T** | **−15 〜 −20 %** | `kf` のみ | ±20 K（目安） |
| **5** | **摩擦係数 μ** | **−4 〜 +23 %** | `Qp`（摩擦丘）と `ϖ(a)`（不均一変形） | ±30 %（目安） |
| **6** | **速度 v** | **+18 % 〜 0 %** | `kf`（＋）と `μ`（−）の**差し引き** | 40 → 160 mpm |
| **7** | **張力**（巻取パスのみ） | **−5 %** | 出口の境界条件 `f(0) = −σ_f·h₂` | 0 → 20 MPa（目安） |
| **8** | **ロール径 R** | **+2.6 〜 +4.5 %** | `Ld`（√R）＋ `Qp` | Φ930 → Φ885（研磨限） |

> 5・6 の幅が広いのは誤差ではありません。**厚板パスと薄板パスで順位そのものが入れ替わる**
> のが正しい姿で、その理由は「§2 なぜ順位が入れ替わるのか」に書きました。
> **2026-09-15 に核を Orowan（不均一変形・すべり／固着）にして数字を取り直しました** —— 摩擦の効きは
> 旧核（Coulomb）の +102 % から +23 % へ、張力は −23 % から −5 % へ小さくなり、順位が動いています。

### まず覚えるなら、この 3 つ

1. **荷重は板幅にきっちり比例する**（弾性値 1.000）。幅を 1.6 倍にすれば荷重も 1.6 倍。
   —— 唯一、疑う余地のない関係です。
2. **厚板では圧下量と温度、薄板では圧下量と摩擦**が効きます。
   分ける物差しは **`Ld/h̄`（接触弧長 ÷ 平均板厚）** ただ 1 つ。
3. **速度は「上げれば荷重が上がる」とは限りません。**
   巻取パスでは**速くしても荷重は動きません**（実測 ∂lnF/∂lnv ＝ **−0.001**。ひずみ速度で硬くなるぶんを摩擦の低下が食う）。

## 1. 要因ごとの詳説

### 各パスの姿（これを見ながら読んでください）

| 条件 | 荷重 | kf | Ld | **Ld/h̄** | Δ（＝h̄/Ld） | 平均面圧 | **摩擦丘** | μ | ひずみ速度 | m_eff |
|---|---|---|---|---|---|---|---|---|---|---|
| 厚板段 530→455 | 1,808 t | 69.0 MPa | 183.3 mm | **0.37** | 2.69 | 73 MPa | **1.02 倍** | 0.320 | 0.83 /s | 0.114 |
| 中間 213→132 | 2,429 t | 88.2 MPa | 190.3 mm | **1.10** | 0.91 | 94 MPa | **1.34 倍** | 0.307 | 3.77 /s | 0.097 |
| 仕上げ 26→16 | 1,467 t | 97.6 MPa | 68.8 mm | **3.28** | 0.31 | 157 MPa | **2.03 倍** | 0.311 | 9.41 /s | 0.090 |
| 巻取 16→8 | 2,020 t | 111.3 MPa | 62.1 mm | **5.18** | 0.19 | 240 MPa | **3.30 倍** | 0.326 | 9.3 /s | 0.081 |

「摩擦丘」の列は、**同じパスを μ → 0 で解いたときの荷重の何倍か**です。
つまり**摩擦が作っている «山» そのもの**で、幾何のぶんは含みません。

**面圧に注目**してください。変形抵抗 `kf` は 69 → 111 MPa と **1.6 倍**しか増えていないのに、
平均面圧は 73 → 240 MPa と **3.3 倍**になっています。
**差を作っているのは材料ではなく摩擦丘**で、**1.02 倍 → 3.30 倍**と 3.2 倍になっています。

- 厚板段の **1.02 倍** … 摩擦が無くても荷重はほぼ全部出る。**面圧 ≒ 素の変形抵抗**（Orowan では境界の圧力が k' の 0.91〜0.93 なので、平均面圧は k' をわずかに下回る）。
- 巻取パスの **3.30 倍** … **荷重の 7 割は摩擦が作っている**。弧の 55 % は固着していて、そこでは摩擦丘が指数でなく直線で伸びる。

**薄くなるほど「材料が硬いから重い」のではなく、「逃げ場が無いから重い」**のです。
（摩擦丘が `Ld/h̄` に対して単調に増えることを判定に固定しています ―― これが摩擦丘の正体です）

### ① 材質 —— 変形抵抗の絶対値（影響度 +280 %）

**何が起きているか**
同じパス・同じ温度・同じ速度でも、材料が変われば荷重は **4 倍近く**変わります。

| 材質 | kf | 荷重 | 最小比 |
|---|---|---|---|
| A1050 純アルミ | 41.4 MPa | 615 t | 1.00 |
| A1100 純アルミ（Cu 添加） | 41.9 MPa | 621 t | 1.01 |
| A4045 Al-Si（ろう材） | 62.0 MPa | 924 t | 1.50 |
| A3003 Al-Mn | 63.8 MPa | 951 t | 1.55 |
| A6061 Al-Mg-Si | 83.7 MPa | 1,255 t | 2.04 |
| A5052 Al-2.5Mg | 97.6 MPa | 1,467 t | 2.39 |
| A5083 Al-4.5Mg | 135.1 MPa | 2,048 t | 3.33 |
| A7075 Al-Zn-Mg-Cu | 153.4 MPa | 2,334 t | **3.80** |

（仕上げ 26 → 16 mm・420 ℃・80 mpm で通した実測。LN_A は全材質一律に −1.75 動かした仮置き —— README 0-2）

**なぜそうなるか**
固溶した元素が転位の動きを邪魔します。Mg は特に効きが強く、
A5052（Mg 2.5 %）→ A5083（Mg 4.5 %）で **kf が 1.38 倍**になります。

**現場での意味**
**パススケジュールを材質ごとに分けるのは «念のため» ではなく必然**です。
A1100 のスケジュールで A7075 を通せば、同じパスで荷重が 3.8 倍 ＝ ミルの定格を軽々と超えます。

**本アプリでの扱い**
Sellars–Tegart の構成式（§3）の材料定数 `Q_ACT / N_EXP / ALPHA / LN_A` として
8 材質ぶん持っています。**役割が分かれている**のがポイントで、
`Q` は温度依存だけ、`n` と `α` はひずみ速度依存の「形」だけ、`A` は絶対値だけを決めます。

### ② 圧下量 Δh（影響度 +34 〜 +138 %）

**何が起きているか**
圧下量は**5 つの経路**で同時に効きます。足し算になるので、感度が 0.4 から 1.25 まで振れます。

| 経路 | 弾性値への寄与 | 中身 |
|---|---|---|
| **幾何** | **必ず +0.5** | `Ld = √(R·Δh)` なので、Δh が 4 倍で Ld は 2 倍 |
| **摩擦丘** | `Ld/h̄` が大きいほど大 | Ld が伸びれば材料の「逃げ道」がさらに遠くなる |
| **ひずみ速度** | 圧下率の小さいパスほど大 | Δh を増やすとひずみ ln(h_in/h_out) も増え、`kf` が上がる |
| **ひずみの過渡** | 厚板段で＋ | 圧下が小さいパスは立ち上がりの途中で終わる。Δh を増やすと定常値へ近づいて硬くなる |
| **バイト内の発熱** | − | 圧下が大きいほど加工発熱で温まり、`kf` が下がる（中間パスで −0.05） |

**実測（∂lnF/∂lnΔh）**

| 条件 | Ld/h̄ | 感度 | 読み方 |
|---|---|---|---|
| 厚板段 530→455 | 0.37 | **0.570** | ほぼ幾何どおり ＋ 過渡域のぶん |
| 中間 213→132 | 1.10 | **0.425** | 圧下率が大きく、ひずみ速度の寄与が薄い。発熱が引く |
| 仕上げ 26→16 | 3.28 | **0.919** | 摩擦丘が効き始め、ほぼ「比例」に |
| 巻取 16→8 | 5.18 | **1.253** | **圧下量を 1 割増やすと荷重が 1.25 割増える**（旧核 1.6 —— 固着で摩擦丘が直線になったぶん） |

> **単調ではない**ことに注意してください（0.570 → 0.425 → 0.919 → 1.253）。
> 厚板段で中間より高いのは、**圧下率が小さいパスほど「Δh を増やすとひずみも増える」度合いが強い**
> ためです。この非単調は判定にも書き残してあります（`tools/sensload.mjs`）。

**現場での意味**
**薄いパスで「あと 1 mm 落とそう」は、厚いパスの 2〜3 倍重い**ということです。
巻取パスで圧下量を 10 % 増やすと荷重は 12〜13 % 増えます。

### ③ 板幅 w（影響度 +60 %）

**何が起きているか**
実測の弾性値は **1.000**（4 パスすべて）。**きっちり比例**します。

**なぜそうなるか**
熱間圧延は**平面ひずみ**です。幅方向にはほとんど流れない（幅広がりは数 % 以下）ので、
幅を増やすことは「同じ断面をもう 1 枚並べる」ことと同じです。

**現場での意味**
唯一、**暗算が当たる**要因です。1,330 mm で 2,000 t なら 1,600 mm では 2,406 t。
逆に言えば、**広幅材はそれだけでミルの能力を食います**。

**落とし穴**
弾性値 1.000 は「幅が荷重に効かない要因を一切持たない」という意味ではありません。
**幅端の冷え（エッジチル）と幅方向の荷重分布**は別に解いており（`Rolling.widthChill`・影響係数法）、
そちらはクラウンと平坦度に効きます。**荷重の «合計» には比例でしか効かない**、が正確な言い方です。

### ④ 摩擦係数 μ（影響度 −4 〜 +23 %）—— 順位が最も動く要因

**何が起きているか**
μ は **`Qp`（摩擦丘）と、不均一変形の係数 `ϖ(a)`** を通って効きます。`kf` にも `Ld` にも触りません。
摩擦丘の高さは **`Ld/h̄`** で決まるので、**μ の効きは板厚で桁が変わります**。

**実測（∂lnF/∂lnμ）**

| 条件 | Ld/h̄ | 感度 | μ を ±30 % 振ったときの荷重 |
|---|---|---|---|
| 厚板段 530→455 | 0.37 | **−0.086** | **−4.4 %** ―― ほぼ効かない（向きは逆） |
| 中間 213→132 | 1.10 | **0.107** | +5.8 % |
| 仕上げ 26→16 | 3.28 | **0.353** | +20.3 % |
| 巻取 16→8 | 5.18 | **0.389** | **+22.6 %** ―― 固着で頭打ち |

**現場での意味**
**「クーラントが悪いと荷重が上がる」は、薄板パスでだけ正しい**ということです。
厚板段で荷重が高いときに潤滑を疑っても、そこはほぼ効きません（−4 %）。
巻取パスでも効きは **+23 %** で、旧核（Coulomb）の「荷重が 2 倍」ほどではありません ——
**弧の半分以上が固着していて、摩擦を上げても圧力の山はそれ以上高くならない**からです。

**なぜ「μ を上げると荷重が増える」のか**
材料は接触面でロールに掴まれていて、横（入口・出口）へ逃げるには摩擦に逆らって滑るしかありません。
**掴む力が強いほど逃げにくく、圧力が中央へ向かって積み上がります**。
接触弧が長く板が薄いほど「逃げるまでの距離」が長いので、山は高くなります。

**固着（sticking）という上限 —— 荷重にも効く**
μ·p が材料のせん断降伏 `k'/2` を超えると、界面は**滑るのをやめて材料の中で切れます**（固着）。
Orowan の理論では `a = 2μp/k' ≥ 1` で固着に切り替わり、その区間の摩擦丘は指数でなく**直線**で伸びます。
巻取パスでは弧の **55 %**、仕上げ 26 → 16 では **28 %** が固着しています。旧核はこの上限をトルクにしか
効かせておらず、巻取パスの荷重が 15 % 過大でした。

**厚板段で向きが逆になる理由**
Ld/h̄ < 1 では摩擦丘がほぼ無く、代わりに不均一変形の係数 `ϖ(a) = 1 − (1 − π/4)·a²` が効きます。
表面で摩擦のせん断が掛かっているぶん、降伏に要る**法線圧力が下がる**（降伏条件の中でせん断が先に
使われる）ので、μ を上げると荷重はわずかに**下がります**（−0.086）。厚板の圧下で知られる «Δ 効果»
（冗長せん断で平均圧力が上がる）は Orowan には入っていません —— どちらが実機に近いかは
厚板段のパスごとの荷重が要ります（README 0-4）。

### ⑤ 温度 T（影響度 −15 〜 −20 %）

**何が起きているか**
温度は **`kf` だけ**を通って効きます。経路が 1 本しかないので、**どのパスでもほぼ同じ効き方**です。

**実測（∂lnF/∂T）**

| 条件 | 感度 | 40 K 振れたときの荷重 |
|---|---|---|
| 厚板段 530→455 | **−4.93 %/10 K** | −19.7 % |
| 中間 213→132 | **−4.20 %/10 K** | −16.8 % |
| 仕上げ 26→16 | **−3.92 %/10 K** | −15.7 % |
| 巻取 16→8 | **−3.84 %/10 K** | −15.4 % |

**覚え方: 熱間アルミは「10 K で 4〜5 %」**。

**なぜそうなるか**
Zener–Hollomon パラメータ `Z = ε̇·exp(Q/RT)` の指数部が効きます。
A5052 の活性化エネルギー `Q` は 175 kJ/mol なので、430 ℃ 付近で 10 K 上がると
`Z` は **1/1.52 倍**になります。応力はその **m_eff 乗**で追うので（この条件で 0.114）、

```
      1.52^0.114 = 1.049   →   −4.9 %/10 K
```

**実測の −4.93 %/10 K とぴたり合います。**
ここで使う指数が `1/n`（＝ 0.20）ではなく `m_eff`（＝ 0.114）であることが要点です ——
`1/n` で計算すると −8.8 %/10 K となり、**8 割も過大**になります。薄いパスほど応力が高く m_eff が
小さい（0.081）ので、温度の効きも小さくなります。

**現場での意味**
- **抽出温度のばらつきがそのまま荷重のばらつき**になります。±20 K ＝ ±10 %。
- **パス間の待ち時間**は温度を通じて荷重に効きます。板が薄いほど冷えが速いので、
  **仕上げ段で手待ちが入ると次のパスが重くなる**。
- 逆に、荷重が高いときの対策として「温度を上げる」は**最も効率が良い**（10 K で 5 %）。

**落とし穴 —— 板厚方向の温度差**
板の温度は 1 つではありません。本アプリは板厚を **9 層**に分けて 1 次元熱伝導を解いており、
`kf` は**層ごとに評価して平均**しています。
表層が冷えているパスでは、平均温度で 1 回評価するより荷重が高く出ます。
（「表層硬化ぶんを別係数で掛ける」という二重計上は、実測で見つけて外しました）

### ⑥ 張力（巻取パスのみ・影響度 −5 %）

**何が起きているか**
前方張力は出口で材料を引くので、**出口の圧力の境界条件が `k'` から `k' − σ_f` に下がり**、
そこから積み上がる圧力の山ごと低くなります。本アプリは Orowan の境界条件 `f(0) = −σ_f·h₂` として
そのまま入れています。

**実測** —— 巻取パスで **−2.7 %/10 MPa**。20 MPa 掛ければ **−5.4 %**。
旧核は «見かけの変形抵抗 kf − σ_t» として弧の全体から引いていたので **−23 %** と 4 倍に出ていました。
境界条件として入れると、張力が効くのは出口の近くだけで、中立点から入口側の山には届きません。

**現場での意味**
可逆ミルでは**巻取パスにしか張力がありません**。
粗・仕上げパスでこの数字を持ち出すと、**実機に無い量が効いているように見えます** ——
この資料の表で張力を巻取パスにしか書いていないのはそのためです。

### ⑦ 速度 v（影響度 +18 % 〜 0 %）—— 符号が変わる唯一の要因

**何が起きているか**
速度は**互いに逆を向く 2 つの経路**で効きます。

| 経路 | 向き | 中身 |
|---|---|---|
| **ひずみ速度** | **＋** | 速いほどひずみ速度が上がり、`kf` が `ε̇^m_eff` で増える |
| **摩擦** | **−** | 速いほど油膜が厚くなり、`μ ∝ (60/v)^0.1` で減る → 摩擦丘が低くなる |

**実測（∂lnF/∂lnv を分解）**

| 条件 | **実際** | うち ひずみ速度 | うち 摩擦 | m_eff |
|---|---|---|---|---|
| 厚板段 530→455 | **+0.120** | +0.112 | +0.008 | 0.114 |
| 中間 213→132 | **+0.079** | +0.090 | −0.011 | 0.097 |
| 仕上げ 26→16 | **+0.040** | +0.076 | −0.035 | 0.090 |
| 巻取 16→8 | **+0.005** | +0.045 | −0.039 | 0.081 |

（残差 < 0.001 ―― この 2 経路で説明しきれています。`tools/mtrace.mjs`）

**現場での意味**
**「速度を上げたら荷重が上がった／下がった」から m（ひずみ速度感受性）を読んではいけません。**
厚板段では実際の変化がほぼ m_eff と一致しますが（0.120 対 0.114 —— 不均一変形では摩擦が逆向きに
効くので、速くして μ が下がるとわずかに**足されます**）、巻取パスでは**ほぼゼロ**です（+0.005 対 +0.081）。
**摩擦が m を食っている**のであって、m が小さいのではありません。«うち ひずみ速度» が m_eff より小さいのは、
弧の半分が固着していて μ にもひずみ速度にも鈍くなっているぶんです。

---

### ⑧ ロール径 R（影響度 +2.6 〜 +4.5 %）

**何が起きているか**
`Ld = √(R·Δh)` なので幾何だけで +0.5、さらに `Ld/h̄` が伸びて摩擦丘も上がります。
実測の感度は **0.515（厚板）〜 0.894（巻取）**と**大きい**。

**なのに影響度が小さい理由**
**実機ではロール径がほとんど動かないから**です。
新品 Φ930 から研磨限 Φ885 まででも **−4.8 %** しか細くなりません。
感度 0.894 × 振れ幅 4.8 % ＝ **4.5 %**。

**これが「感度」と「影響度」を分ける理由です。**
感度だけ見るとロール径は摩擦係数と並ぶ大物に見えますが、現場では動かないので効きません。

**現場での意味**
キャンペーン初日（新品）と末日（研磨限）で**同じスケジュールなら荷重が 3 〜 6 % 違う**。
ゲージメータ式の精度を詰めるときは、**ロール径を実測値で入れる**意味があります。

## 2. なぜ順位が入れ替わるのか —— `Ld/h̄` という 1 本の物差し

厚板パスと薄板パスで要因の順位が変わるのは、**接触弧長と板厚の比 `Ld/h̄`** ただ 1 つで説明できます。
（その逆数が**不均一変形係数 Δ ＝ h̄/Ld**。ワニ口の深さを決めているのと同じ量です）

```
  Ld/h̄ が小さい（厚板・Δ 大）              Ld/h̄ が大きい（薄板・Δ 小）
  ┌────────────────┐                       ┌────────────────┐
  │ 接触弧 ← 短い                          │ 接触弧 ←──── 長い
  │ 板厚   ↕ 厚い                          │ 板厚   ↕ 薄い
  └────────────────┘                       └────────────────┘
   材料は «横へ逃げやすい»                  材料は «逃げ場が無い»
   → 摩擦丘が低い                           → 摩擦丘が高い（弧の半分は固着）
   → μ はほぼ効かない（−0.086）             → μ が効く（0.389。固着で頭打ち）
   → 変形は表層に集中（ワニ口が出る）        → 板厚いっぱいに均一に変形
   → 荷重 ≒ kf × 接触面積                   → 荷重 ≫ kf × 接触面積
```

| `Ld/h̄` | パス | 摩擦丘 | ∂lnF/∂lnμ | 荷重を決めているもの | 荷重が読めないときに疑う順 |
|---|---|---|---|---|---|
| **< 1**（厚板） | 厚板段 | 1.02 倍 | −0.086 | **変形抵抗がほぼ全部** | ① 抽出温度 ② 材質 ③ 圧下量 |
| **1 〜 2**（中間） | 中間 | 1.34 倍 | 0.107 | **まだ変形抵抗が主**（摩擦は 3 割弱） | ① 温度 ② 圧下量 ③ 潤滑 |
| **3 前後**（仕上げ） | 仕上げ | 2.03 倍 | 0.353 | 変形抵抗と摩擦が**ほぼ半々** | ① 圧下量 ② 潤滑 ③ 温度 |
| **> 5**（巻取） | 巻取 | 3.30 倍 | 0.389 | **摩擦丘が過半**（荷重の 7 割）だが**固着で頭打ち** | ① 圧下量 ② 潤滑・ロール表面 ③ 温度 |

**これが実務で一番使える 1 枚**だと思います。
「荷重が計算と合わない」ときに**どこを見に行くかが板厚で変わる**、ということだからです。

## 3. モデルの «作り» で効いていること

ここまでは「外から与える量」の話でした。ここからは**モデルの組み立て方そのもの**が
荷重の数字をどれだけ動かすかを、実測で示します。
**同じ条件でも、解き方を変えると数 % 動きます** ―― それが精度の下限を決めています。

### ロール弾性扁平（Hitchcock）

ロールも弾性体なので、押しつけられると接触部が平たく潰れて**接触弧が伸びます**。
伸びた接触弧はさらに荷重を上げるので、**荷重 → 扁平 → 接触弧 → 荷重** の輪を解く必要があります
（本アプリは緩和つきの不動点反復で、残差 1e-5 まで 3 〜 6 回）。

| 条件 | Ld/h̄ | 剛体ロールと比べた荷重の増分 |
|---|---|---|
| 厚板段 530→455 | 0.37 | **+0.4 %** |
| 中間 213→132 | 1.10 | +0.7 % |
| 仕上げ 26→16 | 3.28 | +2.0 % |
| 巻取 16→8 | 5.18 | **+3.3 %** |

**薄いパスほど効きます**（面圧が高く、接触弧が短いので相対的に伸びが大きい）。
厚板段で 0.4 % なら無視できませんが小さく、**巻取パスで 3.3 % は無視できません**。

### 接触弧の中のひずみ速度分布

ひずみ速度は接触弧の中で一定ではありません。**出口で 0、入口で最大**です。

```
      ε̇(φ) = 2·Q_flow·tanφ / h(φ)²
```

接触弧を **1 点（平均のひずみ速度）で代表させる**と、荷重が**過大**に出ます。
`asinh` が**上に凸**（増え方がだんだん鈍る）だからで、Jensen の不等式から

```
      σ( ε̇ の平均 )   >   σ( ε̇ ) の平均
      ↑ 1 点で代表させた値        ↑ 分割して平均した値（正しい側）
```

となります。**凸性が強いほど差が開く**ので、この差は「モデルの粗さ」の目安にもなります。

| 条件 | 1 点評価にすると |
|---|---|
| 厚板段 530→455 | **+3.9 %** |
| 中間 213→132 | +4.1 % |
| 仕上げ 26→16 | +4.4 % |
| 巻取 16→8 | +4.9 % |

**全パスで 3.9 〜 4.9 % 一律に高く出ます。** 本アプリは接触弧の 129 点それぞれで局所のひずみ速度から
変形抵抗を出し、Orowan がその k'(x) をそのまま受けます（出口の ε̇ → 0 には弧平均の 1/10 の下限）。

### ひずみ速度感受性 m は「定数」ではない

`m` を材料定数として持つのは**間違い**です。双曲線正弦則から解析的に導けます。

```
      σ = (1/α)·asinh[(Z/A)^(1/n)]     （Sellars–Tegart / Garofalo）
      Z = ε̇·exp(Q/RT)

  ここから                              tanh(α·σ)
      m_eff ≡ ∂lnσ/∂lnε̇  =  ────────────────
                                  n · α · σ
```

同じ A5052 でも **520 ℃/0.5 s⁻¹ と 380 ℃/50 s⁻¹ で 2 倍以上**違います（`tools/modeltrace.mjs`）。
低応力側では `1/n` に漸近し、高応力側では小さくなります。
（数値微分との一致を判定に固定しています ―― 最大ずれ 0.000 %）

**なぜこの形にしたか**
以前は経験式 `C·exp(−b·ΔT)·ε̇^m` で `m` を荷重に合わせて動かしていました。
すると `Q_fit = b·R·T_ref²/m` の関係で**温度依存まで一緒に動いて**しまい、
`n = 1/m` を固定したせいで `α` が辻褄合わせに使われ、
**8 材質中 6 つで n・α がアルミの公表値の帯（n 4.0〜6.5・α 0.012〜0.050）を外れて**いました。
物理パラメータで持つ形に直して、**全 8 材質が帯の中**に入りました。

**荷重の較正で動かしてよいのは `A`（＝ `LN_A`）だけです。**

### 荷重とトルクを両方使うと m と μ が分けられる

荷重だけを見ていると、`m` を上げても `μ` を上げても荷重は増えるので**区別できません**。
本アプリは圧力分布そのものを解き（Orowan の理論）、
**荷重は分布の積分、トルクはロール面の摩擦力のモーメント**として**同じ分布から**出しています。

| | ∂ln/∂ln m | ∂ln/∂ln μ |
|---|---|---|
| **荷重 F** | 0.604 | 0.364 |
| **トルク T** | 0.634 | 0.350 |

**行列式 −0.020**（2 本の向きのなす角の sin ＝ 0.044）。
**核を Orowan にしてからは、荷重とトルクは m にも μ にもほぼ同じ比で反応するので、この 2 つだけでは
m と μ を実用上分けられなくなりました**（旧核では sin 0.507）。理由は固着 —— 弧の半分でせん断応力が
k'/2 に張り付くと、トルクも荷重と同じく «変形抵抗 × 面積» で決まり、μ の情報を失います。
**μ を決めるには先進率（中立点の位置）が要ります** —— §6 ④、`PROCESS.FWD_SLIP_MEAS`。
以前はトルクが「荷重 × 一定アーム比」＝ 荷重の定数倍でしかなく、**行列式が 0**（＝ 分けられない）でした。

## 4. 荷重に「効かない」が、誤解されやすいもの

| 量 | 荷重への効き | 実際に効くもの |
|---|---|---|
| **ミル定数**（226 〜 296 t/mm） | **効きません** | **板厚**。同じ荷重でもミルが伸びればギャップが開き、板が厚くなる |
| **バックアップロール径** | ほぼ効きません | **クラウン・平坦度**（ロール系のたわみ剛性） |
| **主機のトルク能力** | 効きません | **速度**。トルクが足りなければ速度が落ち、その結果ひずみ速度が変わって初めて荷重が動く |
| **圧下位置（スクリュー）** | 直接は効きません | **Δh**。スクリューは Δh を決め、Δh が荷重を決める |
| **BUR のすべり** | 効きません | **逆転の加速度**。BUR を滑らせない上限 47.8 mpm/s が主機の能力より先に効く |

**ミル定数の位置づけ**は特に混同されやすいので補足します。
ミル定数は**荷重の «原因» ではなく «結果の受け皿»** です。

```
   圧下位置 S  ──┐
                 ├──→  Δh  ──→  荷重 F  ──→  ミルの伸び x = f(F)  ──→  実板厚 h = S + x
   材料の硬さ ──┘                                  （ゲージメータ式）
```

実機の測定値（0〜1 mm 226／1〜2 mm 244／2〜3 mm 267／3〜4 mm 281／4〜5 mm 296 t/mm）が
示しているのは、**ミル定数は一定ではない**ということです ――
ハウジング・チョック・軸受のがたが**荷重で締まるほど硬くなります**。
2,600 t での伸びは、従来の「550 t/mm 一定」なら 4.73 mm ですが、
**実機の表では 9.34 mm**（約 2 倍）。板厚精度に直結します。

| P23 16 → 8（巻取・50 mpm） | 5.17 | 2,002 t | 1,725 t | **0.862** | 57 % | 11.3 / 14.7 % |

読み取れること（**ここまでは実測、この先の «だから» は推論です**）:

1. **厚板段の 9 % は不均一変形の効き**です。Δ ＝ h̄/Ld が 2〜4 の厚板段は固着が無く、差はすべて ϖ(a) と
   傾斜 2 平面の境界圧（入口・出口で p/k' ＝ 0.91〜0.93）から来ています。中級テキストが「Karman より Orowan」と
   言っている条件そのもので、**§6 の旧版で «厚板段で数 %・優先度低» と置いていたのは過小評価**でした。
2. **薄板段の 13〜14 % は固着の効き**です。いまは τ ＝ μp の摩擦丘を圧力に使い、せん断の上限 k はトルクにしか
   効かせていません。Orowan では弧の 30〜57 % が固着になり、その区間の摩擦丘は指数でなく直線で伸びます。
3. **μ の感度は核の性質**です。巻取パスで μ を 0.16 → 0.42 に振ると、いまの核は荷重が **2.85 倍**、Orowan は
   **1.58 倍で頭打ち**。`tools/loaderr.mjs` が出していた «巻取パスは μ を ±3.7 % で知らないと荷重が ±5 % に
   収まらない» は、Coulomb の核だから出る数字です。
4. **μ ＝ 0.32 は何かを肩代わりしています。** 核を Orowan にすると巻取パスが 1,725 t で実機の帯（2,400〜2,900 t）を
   割り、μ を 0.42 まで上げても 1,862 t までしか戻りません。**足りない 3〜4 割は摩擦では埋まらず、変形抵抗の側**
   （バイト内の冷え ②、ひずみ依存と残留ひずみ ③）で埋まるべき量です。文献の μ が 0.05〜0.20 であることとも
   向きが合っています。この切り分けができるのは、Orowan にして初めてです。

### 6-2. 実装の計画（優先順）

#### ① Orowan を荷重の核にする（Bland–Ford を置き換える）★★★ —— **実装済み（2026-09-15）**

**根拠** —— 中級 §2〜3（式と数値解法、プログラム）、§3.5（剛塑性 FEM との一致）、1995 §2.2（Al 熱延の実務）。

**どう入れるか**
```
  Rolling.orowan(hIn, hOut, R', μ(x), k'(x), w, σf, σb)   → { force, torque, φN, p(x), stickFrac }
```
- `Rolling.solve` の中の `blandFord` をこれに替える。Hitchcock の不動点反復はそのまま（試作でも収束する）。
- **k'(x)・μ(x) を «関数» で受ける**形にしておく —— ②（温度場）と ③（ひずみ依存）と ④（潤滑の頭尾の過渡）の
  受け皿になる。いまの接触弧 8 分割のひずみ速度分布はそのまま k'(x) に載る（試作: 平均との差 −0.6〜−2.2 %）。
- 前方・後方張力は**境界条件** f(0) ＝ −σf·h₂、f(φ₀) ＝ −σb·h₁ で入れ、いまの「kf から引く」近似をやめる。
- 前進率とトルクは**同じ解**（中立点）から出す。`Rolling.forwardSlip` の別式は廃止。
- 刻みは N ＝ 100 で 0.1 % 以内に収束（試作）。`plasticCoef` が数値微分で 2 回呼ぶので、計算量は 4 段 RK × 200 点 ＝
  いまの Bland–Ford 32 点の 25 倍だが、それでも 1 回 0.1 ms 台。
- **較正のやり直しが要る** —— μ と LN_A は Bland–Ford で帯に合わせた値なので、核を替えたら 4 つの帯
  （`tools/calib.mjs`）で取り直す。ただし 6-1 の 4 のとおり μ だけでは戻らないので、②③ を入れてから
  **μ・LN_A・熱伝達率をまとめて**合わせる（パスごとの荷重実績があれば ±5 %、無ければ帯の幅まで）。

**評価器** —— `tools/orowan.mjs`（核の検算: Sims 一致・薄板極限・収束）。実装後は `Rolling.solve` の出力を
同じ 4 パスで突き合わせる項目を足す。回帰は `loadtrace` / `calib` / `loaderr` / `mtrace` / `modeltrace`。

**必要な実機データ** —— **無し**（理論のみ）。較正の取り直しには ④ の先進率 1 点があると μ と k を分けられる。

**入れた結果** —— `Rolling.orowan` を核にし、`Rolling.solve` は k'(x)（129 点）と μ を弧に沿って渡す。張力は出口の
境界条件、前進率とトルクは中立点から。アプリ内の solve は独立実装（`tools/orowan.mjs --app`）と 4 パスとも 0.05 % 以内で
一致。同じ入力で旧核より **厚板段 −8〜9 %・仕上げ −13.5 %・巻取 −15 %**（実機ロット 23 パス）。solve 1 回は 1.0〜1.5 ms
（旧核 0.2〜0.7 ms。k'(x) のグリッドは扁平半径が 0.2 % 以上動いたときだけ作り直す）。

**見込まれる効き** —— 同じ入力で **−9 %（厚板段）〜 −14 %（巻取）**（実測、6-1）。厚板段の Δ>1 の過大が外れ、
μ が «すべり域の摩擦» という意味を持つようになる。荷重の絶対値は較正で戻すので、**効きは «形» に出る**
（Ld/h̄ に対する伸び方が変わる）。A1100 の «形のずれ»（`loaderr` 傾き −0.114）がこれで動くかは、②③ と併せて測る。

#### ② バイト内の温度場 —— k'(x, 層) ★★★ —— **実装済み。荷重にはほぼ効かないと分かった**

**根拠** —— 初級 §3.3（流動応力は «その場» の温度・ひずみ速度で決まる）、1995 §2.5（熱伝達率は実機合わせ）。

**いまの状態** —— 変形抵抗は**噛み込む前の**層温度で評価し、ロールへの抜熱（パス平均 25 K、`Rolling.rollChillK`）は
バイトを出たあとで引いている。つまり**バイトの中では板が冷えない**ことになっている。

**どう入れるか** —— ① の k'(x) に、接触弧を N 分割して各点で層温度を時間積分した値（既存の層モデル `relax` の
境界にロール接触の熱伝達率 `Rolling.rollHTC` を与える）から k' を出す。加工発熱の分配（既存）も同じ積分に入れる。

**見込まれる効き（見積もり、実測ではありません）** —— 巻取パスは接触時間 0.08 s・熱拡散深さ √(αt) ≒ 2 mm／面で、
板厚 8〜16 mm の 2〜5 割が影響を受ける層。パス平均の抜熱 25 K の半分がバイトの中で効くとして **kf で +5〜10 %**。
薄いパスほど、熱伝導率の高い純アルミ（A1100 の K ＝ 222 は A5052 の 1.6 倍）ほど大きく、**«薄いパスほど荷重が
足りない» という A1100 の形のずれと同じ向き**。

**入れた結果** —— `Rolling.biteLayerTemps` で弧の各点の層温度を解き k'(x) に使う（`PROCESS.BITE_THERMAL`）。
荷重への効きは **−0.3〜−0.8 %** で、上の見積もり（+5〜10 %）は**外れました**。理由は測って分かった: 巻取パスの出口で
表面は 38 K 冷えるが、同じ間に加工発熱が 26 K 入り（板厚に一様）、正味は表面 −12 K・芯 +10 K —— 層平均の変形抵抗は
ほとんど動かない。見積もりは発熱を忘れていた。板の温度の帳簿（`_biteThermal`）は変えていない。
**必要なデータ** —— ロール表面温度があれば熱伝達率を較正できるが、荷重にはこの大きさなので急がない。

#### ③ 変形抵抗のひずみ依存（過渡）＋ 残留ひずみ ★★★ —— **実装済み（係数は仮置き）**

**根拠** —— 初級 (9)〜(11): 流動応力は ε の関数で、荷重には出口ひずみまでの**平均流動応力**を使う。
「(9) は動的再結晶形には適用できない」とあるが、アルミは動的回復形なので**飽和形**が使える。

**いまの状態** —— Sellars–Tegart は定常値だけ。組織の状態量（残留ひずみ ε_ret: 厚板段 0.13・最終パス 0.77）は
持っているのに荷重へ返していない。

**どう入れるか** —— 定常値 σ_ss(Z) に過渡を掛け、起点を ε_ret にする:
```
  σ(ε) ＝ σ_ss · [ 1 − (1 − r₀) · exp( −(ε_ret ＋ ε) / ε_c ) ]      r₀ ＝ 初期降伏比、ε_c ＝ 過渡ひずみ
```
① の k'(x) に ε(x) ＝ ln(h₁/h(x)) を与えれば、平均流動応力 (10) は自動的に弧の積分で出る。
r₀・ε_c は文献の桁（アルミ熱間で ε_c 0.1〜0.3）で仮置きし、`CONFIG.MICRO` に置く。

**必要なデータ** —— 同じ材質で**パス間時間を変えた荷重 2 点**（`DATAREQ` の LOADT）。高温圧縮試験の曲線があれば直接。

**入れた結果** —— `Rolling.transientK`（`MICRO.TRANSIENT`: R0 0.6・ε_c 0.15 の仮置き）。運転側は `_micro` の残留ひずみ
その場の値、予測側は `EPS_RET_PRED` 0.08。効きは **厚板段 −9 %・仕上げ −3 %・巻取 −1〜−3 %**（定常値 σ_ss しか無かった旧版に
対し、過渡域にある厚板段が軟らかくなる向き）。上の見積もり（«巻取で +5〜15 %»）は向きが逆でした —— Sellars–Tegart の
定常値を «残留ひずみで硬くなる» 方向へ足すと考えていたが、飽和形では残留ひずみは «定常値に近づける» だけで、
定常値を超えて硬くはならない。

#### ④ 先進率で μ を «測った値» にする（混合潤滑の代わりに）★★ —— **入口は実装済み（実測待ち）**

**根拠** —— 1995 §2.1・1980 §2.1.4（先進率の測り方 2 つ: 出側板速 ÷ ロール周速、ロール面の傷の転写間隔）、
1990 §2.3（熱間アルミの μ 0.05〜0.20）、初級 §3.1（先進率と中立点の関係）。

**どう入れるか** —— ① で前進率が中立点から出るので、**実測 1 点で μ が決まる**。いまの予測 14.7 %（巻取）が
実機で 2〜8 % なら μ は 0.32 より低く、文献の帯（0.05〜0.20）に入る。`DATAREQ` に **FWDSLIP** を足した。
混合潤滑モデルそのもの（EHL の入口解析）は粘度・粘度圧力係数・粗さのデータが要り、5 点の文献にも式は無いので後ろ。

**評価器** —— `tools/loadtrace.mjs` に「予測前進率 vs 実測」を足した（実測が無い間は参考として毎回出す）。**必要なデータ** —— 先進率 1 点。

**入れた結果** —— `Rolling.muFromForwardSlip`（二分法）と `Rolling.muBase`。`PROCESS.FWD_SLIP_MEAS` に
`{ hIn, hOut, width, speed, T, tension, alloy, f }` を置けば MU はそこから逆算した値になる。いまは null（μ ＝ 0.32 のまま）で、
巻取パスの予測前進率は 16 %。

#### ⑤ 較正を «まとめて» やり直す（①〜③ のあと）—— **仮置きで通してある**

μ（④ の実測があればそこから）・LN_A・熱伝達率を、4 つの帯とパスごとの荷重（LOADTR）で合わせる。

**いまの仮置き** —— ①〜③ を入れると実機ロットの荷重は旧核より 9〜18 % 下がり、4 つの帯のうち 26 → 16 と 16 → 8 が
外れる（運転の区間平均 1,321 t／2,090 t に対し帯 1,530〜2,000／2,400〜2,900）。μ は固着で頭打ちになるので戻せず、
**LN_A（絶対値のつまみ）を全材質一律に −1.75** 動かした（A5052 27.092 → 25.342。Δ −1.5〜−2.0 が帯の内側、
−1.75 で帯の中の位置 0.39／0.68／0.10／0.14）。材質間の比は保ったまま。μ ＝ 0.32 は据え置き（先進率の実測待ち）。
`tools/loaderr.mjs` の «帯で縛れる幅 −14.5〜+26.7 %» は変わらないので、**パスごとの荷重実績が来るまでは
①〜③ を入れても «良くなったこと» をこの幅より細かくは示せない** —— 順番として実績の依頼が先なのは従来どおり。

#### ⑥ ソーキング → 固溶量 → lnA ★ —— 5 点の文献には無い

文献にあるのはソーキングの目的（偏析の均質化・過飽和固溶元素の析出）だけで、荷重との関係は無い。
README 2-5（土公ほか 1991: 3003 は均熱条件で亜結晶粒径が変わる、1100 は変わらない）のとおり、
操業パターン別の荷重が来てから。

#### ⑦ 幅方向 —— スリットモデルの張力フィードバックと形状変化係数 ξ（形状側）

中級 §4.4 の (50)〜(58)。荷重ではなく板クラウン → 形状の話なので README 2-3 のロードマップへ 1 行足した。
分割モデル（影響係数法）は入っている。

### ★★ 優先度 中（変わらず）

| 項目 | 中身 | 見込み |
|---|---|---|
| **厚板段の Δ 効果（冗長せん断）** | Δ ＝ h̄/Ld ＞ 1 の厚板段で平均圧力が上がる効き。スラブ法（Orowan も）には無く、すべり線場か弾塑性 FEM で出る。Orowan の ϖ(a) は逆に μ で圧力を下げる（∂lnF/∂lnμ −0.09）ので、向きが逆の 2 つの効きのどちらが実機に近いかは**厚板段のパスごとの荷重**が要る（README 0-4） | 厚板段で 1 割級の可能性 |
| 弾性入口・出口域 | 薄板・低圧下で接触弧の一部が弾性域。Bland–Ford も Orowan も無視する | 巻取パスで数 % |
| ロール偏心・軸受のがた | 1 回転周期の荷重変動。AGC の効かせてはいけない周波数 | 荷重トレンドの生データが要る |
| 幅広がりの 3 次元流動 | 厚板段は横へ逃げる条件だが幅は接触弧の 7 倍 | 荷重には小、板長 0.25 % |

### ★ 優先度 低

| 項目 | 中身 | 効き |
|---|---|---|
| ロール軸方向の圧力分布 | 影響係数法の先（非ヘルツ接触） | クラウン精度 |
| 加工発熱の η | いまは定数。ひずみ・ひずみ速度依存 | 温度で 1〜2 % |
| 異方性（集合組織） | 耳率に効く | 荷重にはほぼ無関係 |

上に載る、(c) いまの μ ＝ 0.32 が何を肩代わりしているかは、核を替えてからでないと切り分けられない（6-1 の 4）。

## 7. 数字を自分で取り直すには

モデルを直したらこの資料の数字も変わります。**その場で測り直せます。**

```bash
node tools/sensload.mjs     # この資料の §0〜§3 の数字すべて（感度・影響度・材質比較）
```

## 付録: 用語

| 記号 | 読み | 意味 |
|---|---|---|
| `F` | 圧延荷重 | ロールが板を押す力 [t] |
| `w` | 板幅 | [mm] |
| `Ld` | 接触弧長 | ロールが板に触れている長さ。`√(R'·Δh)` [mm] |
| `h̄` | 平均板厚 | `(h_in + h_out)/2` [mm] |
| `Ld/h̄` | ― | **本資料で最も重要な量**。摩擦丘の高さを決める |
| `Δ` | 不均一変形係数 | `h̄/Ld`（`Ld/h̄` の逆数）。Δ>2 で芯に静水圧引張 → ワニ口 |
| `Δh` | 圧下量 | `h_in − h_out` [mm] |
| `R'` | 扁平後のロール半径 | 弾性扁平で素の半径より大きくなる [mm] |
| `kf` | 変形抵抗 | 材料の流動応力 [MPa] |
| `k` | せん断降伏応力 | `kf'/2`。凝着の上限 [MPa] |
| `p̄` | 平均面圧 | `F/(w·Ld)` [MPa] |
| `Qp` | 摩擦丘係数 | `p̄/(1.155·kf)`。面圧が素の変形抵抗の何倍か。**接触弧の幾何（h/h_out）のぶんも混ざる**ので、摩擦だけを見たいなら下の «摩擦丘» を使う |
| 摩擦丘 | ― | **同じパスを μ → 0 で解いたときの荷重の何倍か**。摩擦が作っている «山» そのもの（本資料の表はこちら） |
| `μ` | 摩擦係数 | ロール–材料間 |
| `Z` | Zener–Hollomon パラメータ | `ε̇·exp(Q/RT)`。温度補償ひずみ速度 |
| `Q` | 活性化エネルギー | 温度依存を担う [kJ/mol] |
| `n`, `α`, `A` | 構成式の材料定数 | `n`・`α` はひずみ速度依存の形、`A` は絶対値 |
| `m_eff` | 実効ひずみ速度感受性 | `∂lnσ/∂lnε̇ = tanh(ασ)/(n·ασ)`。**定数ではない** |
| `ε̇` | ひずみ速度 | [s⁻¹] |
| `ε_ret` | 残留ひずみ | 再結晶しきれず次のパスへ持ち越されるひずみ |
| `∂lnF/∂lnX` | 対数感度（弾性値） | 「X を 1 % 増やすと F が何 % 動くか」 |
